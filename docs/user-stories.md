# Setup Manager – Felhasználói történetek

## A program célja

A program célja, hogy az autóverseny-szimulátorokat használó játékosok egyszerűen nyilvántarthassák az autóbeállításaikat és a hozzájuk tartozó köridőket.

## Felhasználói történetek

**1. Setup létrehozása**

Felhasználóként szeretnék új autóbeállítást létrehozni, hogy elmenthessem a különböző autókhoz és pályákhoz használt setupjaimat.

**2. Köridők rögzítése**

Felhasználóként szeretnék egy setuphoz több köridőt hozzáadni, hogy nyomon követhessem a teljesítményemet.

**3. Setupok összehasonlítása**

Felhasználóként szeretnék két, azonos pályához tartozó setupot összehasonlítani a legjobb vagy átlagos köridő alapján, hogy eldönthessem, melyikkel értem el jobb eredményt.

**4. Setupok rendezése**

Felhasználóként szeretném a setupokat a legjobb köridő alapján rangsorolni, hogy könnyen megtalálhassam a leggyorsabbat.

**5. Setup törlése**

Felhasználóként szeretném törölni a felesleges vagy hibásan létrehozott setupokat, hogy a nyilvántartás átlátható maradjon.

**6. Adatok mentése és betöltése**

Felhasználóként szeretném a setupjaimat és köridőimet fájlba menteni, majd később visszatölteni, hogy a program újraindítása után is elérhessem őket.

**7. Hibás adatok kezelése**

Felhasználóként szeretném, hogy a program figyelmeztessen a hibás értékekre, és lehetőséget adjon azok javítására.
